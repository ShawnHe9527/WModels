# R6 结论归档（2026-10-31）

> 本文件固化 R6 阶段的结论与证据，供写作与后续方向参考。
> 详细逐条记录见 `PROJECT_STATE.md` §2.15–2.30；命令与复现见 `runs/`。

## 1. 设置

- 对象：官方 L5PC NEURON 模型的 `apical_51`（11 compartment）
- 状态：9 因子（7 慢门控 + `cai` + `V`），99 维；输入 `u` 85 维（33 own + 51 neighbor + bAP）
- 模型：`Enc(s,u,θ)→z(16)`、`Pred(z,u,θ)→z_{t+1}`、`Dec(z)→ŝ`；残差输出
  `ŝ_t = s_{t-1} + [Dec(z_t) − Dec(z_{t-1})]`
- 训练：T1 自编码器（冻结）→ T2 只训 Predictor；一步教师强制 + 事件加权 + 闭环课程（4→64 步）
- 数据：1 s（`tr_s1/va_s2/te_s3`）与 2 s（`te_s4_2s`），dt=0.025 ms
- 指标：`model/L0`（相对“复制上一帧”的误差比），k=10/200/2000/8000 步（0.25/5/50/200 ms）

## 2. 最佳模型 R2

- 架构：DeepSets Encoder（compartment token 池化）+ MLP Predictor（2×192，零初始化输出）+ 逐 compartment Decoder
- 训练：9000 步、batch 24、L=128、事件加权（`event_weight=10`）、CL 4→64、anchor 0.1
- `te_s4_2s`（256 样本）：k=10/200/2000/8000 = 0.625 / 0.562 / 0.562 / **0.890**，0 发散
- plateau 0.509→0.562、inter 0.620→0.527；Ca 峰 F1 0.359；Vmax 比 0.934

## 3. 诊断与关键实验

| 实验 | 结论 |
|---|---|
| **E2 可预测性** | 输入棘波扰动 0.5 ms：8 trial 均无 >2 mV 分离（plateau 更稳）⇒ **动力学收缩，200 ms 原理可预测**，误差来自模型累积 |
| **E3 CL 消融** | 去掉 CL 后 k=2000 达 1.5e4、k=8000 1.6e31 ⇒ **CL 是稳定化的必要条件** |
| **CL=126** | 更长 CL：k=8000 0.878 + 14/128 发散 ⇒ **64 步接近上限，再长有害** |
| **E4 多 seed** | S1 0.831/0DIV；S2 3.128/**18DIV**；S3 4.781/发散 ⇒ **稳定性跨 seed 差异巨大** |
| **F2a 快照** | S3 在 step 8000 稳定（0.968、0/64），`last`（9000）崩（4.78/18DIV）⇒ **稳定性是间歇的，选模是问题** |
| **F1 降 lr** | S2 2.20/4DIV、S3 128/128 DIV ⇒ **降阶段 B lr 不是解** |
| **F2b 选模** | 最佳稳定快照：S1 0.831、S2 1.757、S3 1.044 ⇒ **平均 ≈1.21，仍劣于 L0** |
| **P3a 慢因子门控** | κ 被一步损失推向过阻尼（0.31–0.79），k=8000 1.014 ⇒ 结构可学但方向错 |
| **P6 T1 逐帧目标** | 全面变差（k=8000 1.040）⇒ **表示不是瓶颈** |
| **C+A（2 s + L=512）** | 0.931 vs R2 0.890 ⇒ 加长数据/窗口无益 |
| **P1 漂移正则** | 1.347 vs 0.941 ⇒ 失败 |
| **scaler** | 旧 400 样本 scaler 比新 2000 样本好 ~12%（0.831 vs 0.941） |
| **provenance** | 参考脚本与原仓库逐字节相同；原仓库默认 NMDA+GABA_A、STP 关闭、GABA_B 未启用 ⇒ 我们的突触配置与原仓库一致；差异在输入协议与建模目标 |

## 4. 核心结论

1. **短/中视界（≤25 ms）稳健优于 L0**：所有可用 seed 的 k≤2000 均 <1。
2. **200 ms 的优势不可跨 seed 复现**：单个 seed 可到 0.737–0.831，但 3 seed 最佳稳定值平均 ≈1.21（劣于 L0）。
3. **CL 是必要稳定器，但会把多数 seed 推向“保守预测”**（≈L0）；好的动力学盆地很少见。
4. **单步 σ 与 `best.pt` 是无效甚至有害的选模准则**：与闭环稳定性系统性脱钩。
5. **表示/容量不是瓶颈**：16 维 latent 足以恢复状态（探针 R² 0.97–0.99），改 T1 目标只会更差。

## 5. 对评估协议的要求（今后必须遵守）

- 至少 **3 seed**，报告 `k=8000` 的**中位数**与**发散率**，而不是单 seed 均值；
- 选模用**闭环验证**（快照 + `va` 闭环误差），不用单步 σ；
- `te_s3/te_s4` 只用于最终模型，不参与中间选择。

## 6. 未解决问题（下一步可能的正面方向）

- **直接多滞后监督**：用 `(z_t, u 摘要)` 直接预测 `s_{t+Δ}`（Δ=512/2048/8000），不经 rollout，
  检验“长视界信息是否可从输入摘要学到”，并可作为粗粒度长程预测器；
- **渐进式长 rollout**：truncated BPTT + 课程（64→256→1024）+ LR 衰减 + EMA，配合闭环选模；
- **线性/SSM predictor + 长序列训练**：把长 BPTT 成本降到 O(L)（Yao 2026 路线），是唯一能
  “真正看到 200 ms”的架构级方案，成本数天。

# R7：长视野诊断与能力边界（2026-10-31）

## 1. 直接 Δ 预测（非因果诊断，路线 1）

`tools/jump_probe.py`：输入 = 初始状态（z16 或 s99）+ `[t0,t0+Δ)` 的输入统计量
（mean/std/max/last，340 维）+ θ；输出 = `s_{t0+Δ} − s_{t0}`。不经过 rollout。
指标 = `model/L0`（L0=复制 s0）。

`va_s2`，3 seed，t0 ∈ {4000,8000,12000}：

| 特征 | Δ=512 | Δ=2048 | Δ=8000（200 ms） |
|---|---:|---:|---:|
| z16 | 0.195–0.197 | 0.397–0.426 | **0.565–0.591** |
| s99 | 0.123–0.145 | 0.322–0.336 | **0.455–0.480** |

**V1 验证**（未见时间点 t0=20000/24000/28000；2 s 数据 `tr_s1_2s → te_s4_2s`）：

| 设置 | z16 Δ8000 | s99 Δ8000 |
|---|---:|---:|
| va 未见 t0 | 0.423–0.445 | 0.357–0.373 |
| 2 s 测试 | 0.453–0.476 | 0.406–0.413 |

**结论**：
- 200 ms 状态**可由输入粗统计 + 初始状态直接预测**，跨 seed、跨数据集稳定；
- **16 维 latent 足够**（z16 0.58 vs s99 0.48）⇒ 降维不是瓶颈；
- 因此世界模型的长程失败是**因果 rollout 的误差累积**，不是信息/容量/可预测性。

## 2. 混合校正（I1）：jump 作为世界模型的辅助

`tools/hybrid_rollout.py`：世界模型 rollout，在 512/2048/8000 步用 jump 校正
`s ← (1−λ)s_roll + λs_jump`。S1，128 trial，k=8000，L1：

| 设置 | λ=0 | λ=0.5 | λ=1 |
|---|---:|---:|---:|
| 含终点校正（512/2048/8000） | 0.831 / 中位 1.40 | **0.586 / 0.817** | 0.633 / 0.797 |
| 无终点校正（512/2048） | 0.831 / 1.40 | 0.821 / 1.312 | 0.881 / 1.362 |

- λ=0 与 `diag` 完全一致（口径已对齐）；
- **中途校正只带来 0.831→0.821 的边际改善**；大幅改善来自终点那次 jump 预测；
- S2/S3 的 rollout 直接发散（inf），中途校正救不回。

## 3. 能力边界（论文主结论）

| 能力 | 数值 |
|---|---|
| 因果世界模型，≤50 ms | 0.52–0.56（所有可用 seed <1） |
| 因果世界模型，200 ms | 0.83，且 3 seed 中 2 个发散/退化到 L0 |
| 非因果粗预测器，200 ms | **0.48–0.58**，3 seed 几乎重合，跨 1 s/2 s 成立 |
| 稀疏中途校正 | 边际（0.831→0.821） |

## 4. 方法学教训（必须写进论文/文档）

1. **单步 σ 与闭环稳定性脱钩**；`best.pt` 选模有害（S1: 0.831→2.824）；
2. **CL 是稳定化的必要条件**（无 CL → 1e31），但 CL=64 已接近上限（126 更差）；
3. **稳定性在训练轨迹上是间歇的**（S3 在 step 8000 稳定、step 9000 崩）；
4. **seed 间从 0.83 到发散** ⇒ 任何结论必须 ≥3 seed + 发效率；
5. 表示/容量不是瓶颈（P6 失败、探针 0.97–0.99、jump 用 z16 仍达 0.58）。
