# 方案：5-seed 单独训练 + 集成 + 鲁棒损失（2026-11-04）

## 1. 动机

- **seed 1 反复“最优”**：A（0.538→均值 0.753）、H1024（0.511→0.588）、E1（0.468→0.867）；
- **单 seed 方差大**：基线 S1 0.831 / S2 3.128 / S3 4.781（2/3 退化）；
- 结论：**任何单 seed 结论都不可信**；需要“分布 + 集成”两层证据。

## 2. 设计

| 项 | 内容 |
|---|---|
| 基座配置 | **A+B**（horizon 512、lags 64/256/512、TBPTT 64）；若 E1-strong 复现则改用它 |
| 种子 | **1–5**（seed 1 已有；2–5 需训练，各 9000 步） |
| 训练 | 每个种子**完全独立**训练（相同超参、不同 seed） |
| 集成 | 每个模型独立 rollout；在评测视界 k 上把 5 个预测**反归一化到物理量后逐元素平均** |
| 产出 | **5 个单模 + 1 个集成 = 6 组结果** |

## 3. 鲁棒损失（“symlog”的对应物）

- DreamerV3 的 **symlog** 针对**重尾幅值**（reward）；我们的问题是**重尾误差**（plateau 11 mV vs linear 2 mV）⇒ **Huber 更合适**；
- 方案：`L = Huber(ŝ − s, β)`，β ∈ {0.01, 0.05}（归一化单位）；1 seed 筛查；
- 若有效，再扩到 3–5 seed；
- 若无效，则只保留“集成”作为 D1/D4 的解法。

## 4. 指标

- 每种子 + 集成：k=2000/8000/16000/32000 的 `model/L0`、发散计数；
- Ca 事件：F1 / precision / recall / 幅度比（单模与集成）；
- 报告方式：**中位数 + 范围 + 集成值**，不用“单 seed 最优”。

## 5. 成本

| 项 | 成本 |
|---|---|
| 4 个新 seed（2–5）× ~2.5 h | **10 h** |
| 集成评测（每 k 一次） | ~30 min |
| Huber 筛查（1 seed × 2 个 β） | ~5 h（可后置） |
| 合计 | **~13 h**（Huber 可分开） |

## 6. 判据（预注册）

1. **集成 ≥ 单模中位数**（同视界）⇒ 集成降方差成立；
2. **5 seed 的均值 ± 范围**作为论文报告口径；
3. Huber：若 200/400 ms 的**极端误差分位数**（如 P90）下降且均值不退化 ⇒ 采纳。
