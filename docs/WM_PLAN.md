# WModel 世界模型计划（唯一当前计划，2026-11-09 起）

> 本文件是**唯一权威的当前计划**；历史讨论与旧计划已合并到此。
> 实验记录/结论在 `PROJECT_STATE.md`；设计事实在 `DESIGN_v4.md` / `MODEL_FACTS.md`。

## 0. 目标与定位

- **总目标**：全神经元的分层联合世界模型（Stage 2）。
- **Stage 1**：`apical_51` 上验证方法论——用**尽可能简单的接口**学到“状态如何演化并预测”，
  而不是靠堆输入细节刷精度。
- **边界**：不改 9 因子定义、不改数据协议（除非开新分支）；所有改动默认关闭、可回退、单变量。

## 1. 当前架构（Stage 1）

```
s_t(9×11) ─► 每 comp MLP ─┐
u_t(28×5) ─► 每 token MLP ─┤
θ(27)、bAP(1) ────────────┤
                          ▼
       Pool[mean/max(hs), mean/max(hu)] + θ + bAP
                          ▼
                fuse MLP → z_t (16, LayerNorm)
                          ▼
   Predictor: [z_t, pooled u, θ, bAP] → Δz → z_{t+1}=z_t+Δz
                          ▼
   Decoder（冻结）: z_{t+1} → 9×11
                          ▼
   ŝ_{t+1} = s_t + Dec(z_{t+1}) − Dec(z_t)
```

- Enc ~344k / Pred ~56k / Dec ~47k（Dec 冻结）；
- 训练：一步 MSE（cai 事件加权）+ 闭环 CL（horizon 512、lags 64/256/512、TBPTT 64）+ anchor（+ 可选 OV）；
- 评测：闭环 rollout，`model/L0`（50/200/400 ms），2 s 盲测 `te_s4_2s`。

## 3. 决策记录（2026-11-09）

| # | 决策 | 依据 |
|---|---|---|
| 1 | **保留突触输入强度**（AMPA/NMDA/GABA、bAP） | 真实突触有强度差异；也是“输入→输出影响”的研究对象 |
| 2 | **保留几何 frac/side** | 电缆方程/电紧张距离对位置敏感 |
| 3 | **输入简化推迟到 Stage 2 前** | 全神经元输入会爆炸；Stage 1 先保精度 |
| 4 | **分层 latent 留给 Stage 2** | Stage 1 只验证方法 |
| 5 | **物理残差只作消融/上界** | 否则被质疑“抄答案” |
| 6 | 当前优先解决“预测不准” | 事件/长程/linear 漂移 |

## 4. 候选改进与判据

### 4.1 显式事件输出（S1-1）
- 事件头：预测未来 Δ=20 ms 是否有 Ca 峰 + 峰时刻（已有 `--event-head` 辅助版，F1 仅 0.269）；
- **显式版**：在预测峰时刻叠加峰模板（或 mixture decoder：连续 + 稀疏事件分量）；
- 判据：F1 ≥0.40，且 200 ms 不退化；否则记录为负结果。

### 4.2 长滞后 OV（S1-2）
- 在 CL 512 轨迹上做 256/512 的 latent 一致性（当前只到 96）；
- 判据：400 ms 改善 ≥10%。

### 4.3 多视界头（S1-3）
- 直接预测 t+64/256/800 的状态（jump 辅助），与 rollout 加权/门控；
- 判据：400/800 ms 改善 ≥10%。

### 4.4 RSSM-lite（后备）
- 无 h 版：`z=μ+σ⊙ε`，prior `p(z|z_{t-1},u_t)`，posterior `q(z|s_t)`，KL balancing + warmup；推理用 μ；
- 判据：F1 ≥0.40 或 200/400 ms ≥10%，不发散。

### 4.5 物理残差（仅消融/上界）
- 门控 ODE 做软先验；闭环用**模型预测的 V**驱动；
- 必须提供：消融、探针（`dm/dt`/`dV/dt`）、反事实、外推（未见 θ/regime/STP）、真值 V 上界对照；
- 若增益主要来自“抄方程”，撤掉。

## 6. 已否决 / 不做

- 快慢双 decoder（E2，崩）；
- dense 损失点（128/128 发散）；
- 单独加长视界（H1024 未复现）；
- 扩散/大 Transformer（算力/数据不匹配）；
- RL 的 value/reward 头（无回报）；
- 物理残差作主模型（只作消融）。
