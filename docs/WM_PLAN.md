## 0. 一页结论

- Stage 1（单段 `apical_51`）的连续误差已到 **0.49–0.51 @200 ms**，接近非因果 jump 上界 **0.48–0.58**；
  在“当前输入 + 9 因子状态”的信息量下，**继续换模块/加宽 latent 的收益接近零**。
- 当前两个主配置候选：
  - **OV**（latent overshooting）：5 seed **0.493 @200 ms / 0.618 @400 ms**；
  - **FW2**（OV + V/cai 逐因子×2）：5 seed **0.508 @200 ms / 0.563 @400 ms**；2 s 盲测（s1）**0.434/0.395/0.401**（50/200/800 ms）。
- **FW2 是论文主配置候选**（400 ms 与 2 s 盲测更稳）；**OV 是 200 ms 对照/次选**。
- 下一步只有三类真正有信息增量：
  1. **新数据信息**：事件密集协议（C2）、STP/GABA_B 隐藏状态（C1）；
  2. **事件级监督**：点过程/峰模板（B2），不是继续调连续 MSE；
  3. **分层/全神经元**：Stage 2 小树 → Stage 3 全细胞。
- 不再把“加宽 latent、加长视界、换更大网络”作为主方向。

## 1. 目标、边界与阶段

### 总目标

构建 L5PC 神经元状态动力学的隐空间世界模型：在保持生物物理状态可解码的前提下，
把 99 维（单段）到约 3944 维（全细胞）的状态压缩到低维 latent，学习闭环动力学，
预测 5–800 ms 的状态/平台/钙事件，并识别主导因子与输入条件。

### 当前阶段

- **Stage 1（当前）**：`apical_51`，9 因子 × 11 隔室 = 99 维；验证“latent + 闭环 + 长视界”方法论。
- **Stage 2（下一步）**：4 个 section / 28 隔室 / 252 维；验证分层联合是否必要。
- **Stage 3（后续）**：196 section / 642 隔室 / 有效 3944 维；全神经元。

### 边界

- 不改 9 因子定义、不改数据划分；所有改动单变量、默认关闭、可回退；
- 不改 `DESIGN_v4.md` / `MODEL_FACTS.md` 的事实定义；
- 物理残差只作消融/上界，不作为主模型；
- 不把 Stage 2/3 的“计划”写成“已完成”。

### 2.2 绝对误差与事件

- 200 ms 的 V MAE：**4–5 mV**；plateau 档 **8.5–12 mV**；linear 档约 1.5–1.8 mV；

## 4. 当前主配置选择（P0）

### 目标

在**同一评测口径**下定稿：FW2 还是 OV，或“FW2 主 + OV 200 ms 对照”。

### 必做

1. 用**同一批 128 trial、同一 t0、同一 5 seed**比较 FW2 vs OV；
2. 同时报：`model/L0`、V MAE、cai MAE、plateau V MAE、Ca 峰 F1；
3. 分 regime 报，不只报总体；
4. 2 s 盲测补齐 5 seed（当前只有 s1）；
5. 结论写成“主配置 + 次选 + 适用视界”，不要只报一个漂亮总数。

### 判据

- 200 ms：不差于 OV 的 0.493 太多（≤0.52）；
- 400 ms：FW2 保持 ≤0.58；
- 2 s 盲测 800 ms：≤0.45；
- 0 发散；3/5 seed 方向一致；
- 若两者互有胜负：**FW2 主配置，OV 作 200 ms 对照**。

> P0 预计 3–5 天；不再新增结构，只做定稿与补齐。

## 5. 下一步三条线（P1–P2）

### P1：事件级路径（C2 → B2）——最优先

**问题**：连续误差接近上界，但 F1 只有 0.25–0.33；事件时序是独立瓶颈。

1. **C2 事件密集协议**（最便宜、最直接）：
   - 提高 plateau/事件比例（例如 44% → 60–70%），trial 数 200 → 500；
   - 重新校准 scaler；重生成一组新数据；
   - 目的：抬高事件信息上界，改善 F1 与 plateau 绝对误差。
2. **B2 点过程/峰模板头**：
   - 每帧 hazard `λ(t)`（log-normal/Weibull）或“事件时刻 + 峰模板”；
   - 损失：负对数似然 + 事件计数匹配 + 峰时刻/幅度回归；
   - 只在事件帧/事件窗口加权，不再用几乎均匀的标量事件权重；
   - 目标：**F1 ≥0.40（先），≥0.50（争取）**；连续指标不退化 >10%。

**判据/回退**：

- C2 数据生成后先跑 FW2 对照，确认连续不退化；
- B2 若 F1 <0.35 或连续退化 >10%，记录负结果，停止事件线，转 Stage 2；
- 不重复“简单 spike-and-slab”与“辅助事件头”。

### P2：新信息/隐藏状态（C1 / A2）

1. **C1 STP + GABA_B + 随机释放**（真正的隐藏状态）：
   - 需可靠 mod 文件；重生成新数据；
   - 目的：检验 latent 是否能吸收未观测的短期可塑性/慢抑制；
   - 判据：隐藏 STP 下 200 ms ≤0.6；若明显崩，说明当前 latent 不足。
2. **A2 输入预览**：
   - 条件在 `u_{t..t+Δ}`（Δ=64/256）；作为**上界/对照**，不是主模型；
   - 目的：验证“输入信息”还能带来多少连续误差下降。
3. **快速 Na/K 通道**：
   - 当前 9 因子没有快速通道；若能补数据，作为辅助状态/事件标签；
   - 不能补数据时，用峰标签/`dV/dt` 替代；不要凭空声称已实现。

> P2 只在 P1 失败或 P1 完成后启动；不要与 P1 并行烧算力。

## 6. Stage 2：分层验证（全神经元的前置）

### 对象

- 4 个 section 小树：`apical_50 → 51 → {52, 53}`；
- 28 个隔室 / **252 维**；
- 树突是二叉树，不是三段串联链。

### 结构

- 隔室 → 段 → 分支 → 全局；
- 自底向上池化 + 图消息；
- 自顶向下反馈；
- **只有隔室层解码物理状态**；段/分支/全局是协调变量。

### 对照

1. **逐段独立**：每个 section 各算各的，最后拼接；
2. **单向串联**：子段预测 → 父段输入；父段不反馈；
3. **分层联合**：双向消息 + 全局 latent + 联合训练。

### 判据（go/no-go）

- 200 ms 分层联合比最好的独立/串联低 **≥10%**；
- 3 个 seed；0 发散；
- 分区域指标不退化；
- 失败 → 回退串联/独立；Stage 2 仍可作为论文主体，Stage 3 不启动。

> Stage 2 是“全神经元”的必要前置；不要直接跳 Stage 3。

## 7. Stage 3：全神经元（全细胞）

### 规模

- 196 section / 642 隔室；有效状态约 **3944 维**；
- apical 9 因子；basal 2 因子；soma/axon 9 因子；mask 必须；
- padded：树突 5751 / 全细胞 5778；
- 数据：有效状态约 **252 GB/组**；补齐张量约 **370 GB/组**。

### 路径

1. 先 **64–128 个代表隔室**子集，证明分层 latent 可行；
2. 再扩到 639/642 全量；
3. 训练：截断反传 64；多滞后 64/256/512；闭环课程；梯度裁剪；有界增量；
4. 评测：逐隔室、逐段、逐分支、分区域；不把 basal 缺失因子算进误差。

### 判据/回退

- 子集 200 ms 不崩、0 发散，才扩全量；
- 子集失败 → 停在子集或 Stage 2；
- 全量数据/算力不足 → 以子集 + Stage 2 为论文边界，不硬上。

## 14. 后续分支：STP + GABA_B + 随机释放（记录 2026-11-11，待确定性模型定稿后启动）

**定位**：独立分支（v6），不与 Stage 1 结果混用；用于科学问题“latent 能否吸收隐藏状态”与随机性建模。

**配置**：
- E：`ProbAMPANMDA_EMS`（AMPA+NMDA+STP）；I：`ProbGABAAB_EMS`（GABA_A+GABA_B+STP）；
- STP：`Use≈0.3–0.5`、`Dep≈100–500 ms`、`Fac≈10–50 ms`；随机释放由 mod 内置 `urand()` 实现（设 RNG 种子）；
- GABA_B：`GABAB_ratio` 按通路 0.2–0.5，`e_GABAB=-97 mV`，τ 3.5/260.9 ms；
- 输入分开记录 `g_GABAA` 与 `g_GABAB`；STP 的 `u,x` **记录但不进状态**（作隐藏标签与探针目标）。

**数据**：5 s/trial，200 trial × 5 个生成 seed（约 35 GB/组，~7 h/组）。

**模型适配**：随机 latent（KL balancing/free bits/重构 s）、分布头（NLL/CRPS）、ensemble、事件头；评测加 `z→u` 探针 R²、NLL/CRPS/覆盖。

**判据**：隐藏 STP 下 200 ms `model/L0 ≤ 0.6`；`z→u` 探针 R² 显著高于随机基线；分布指标优于点预测的 MAE 等价物。

## 15. 2026-11-11 误差分解诊断（D1–D3，FW2，43 plateau trial）

| 分量 | 结果 | 解读 |
|---|---|---|
| 平台**起始**误差 | **3.2 ms** | 起始基本抓对 |
| 平台**幅度**误差 | **9.5 mV** | **主导**：模型显著低估平台幅度 |
| 平台**持续时间**误差 | 26 ms | 次要但明显 |
| 基线误差 | 0.04 mV | 可忽略 |

- **这推翻了“主要是时序问题”的假设**：onset 只差 3.2 ms，真正的大头是**幅度（9.5 mV）与持续时间**；
- 因此下一步改进应优先 **幅度校准/尾部损失**（而不是继续做事件时序头）；
- D2（mid-course 校正）结果异常（校正后 rollout 发散），暂不可用，需修工具后再用。
