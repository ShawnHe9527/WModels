## 5. 种子策略（重要：seed ≠ 数据量）

- **增加 seed 不增加数据体积**：同一份数据集，只是多训几次；成本是**训练时间**，不是磁盘。
- 当前主结果已有 **3 seed**（A+B），足够支撑论文主结论；
- 若时间允许，最终配置补到 **5 seed**（+2 次 × ~2.3 h），主要为了给出更稳的均值/方差；
- **不建议**为了 seed 牺牲全细胞探索的预算：全细胞的数据/模型成本远大于 seed。

## 6. 全细胞扩展（L5PC 196 section / 639 segment）

### 6.1 规模
- 状态：9 × 639 ≈ 5751 维（现在是 99）；
- 输入：逐 segment 突触（5 通道 × 639 ≈ 3200 维 + bAP）；
- 数据：每 trial ≈ 1.8 GB（9×639×80000×4B），200 trial ≈ **370 GB/组**；
- 生成时间约为现在的 ~60×（数小时–数天/组）。

### 6.2 模型必须改的地方
- **Encoder**：从“全局池化到一个 16 维 z”改为**沿形态树的分层池化**（segment → branch → 全局），
  每 branch 一个 latent（如 16 维）+ 全局 latent；
- **Latent**：多 latent（全局 + 局部），否则 5751 维装不下；
- **Predictor**：对 branch latent 做**图/消息传递**或注意力，而不是单个 MLP；
- **Decoder**：逐 segment 共享 MLP（天然可扩展）；
- 评测：逐 compartment 的 L0/L2 + 区域级指标。

### 6.3 BPTT 在全细胞层次会爆炸吗？

**会更容易不稳定，但可控**，关键手段：
- **TBPTT（必须）**：chunk 64（或更小）截断，避免 512 步 × 639 segment 的完整反传；
- **梯度裁剪**（如 0.1–0.3）+ **有界增量**（`Δs = scale·tanh`）；
- **渐进课程**：64 → 128 → 256 → 512，不要一步到位；
- **分层结构天然提供“收缩”**：branch 级消息传递 + 残差/LayerNorm 有助稳定；
- **梯度检查点**（CPU 上可用）控内存；
- 若仍不稳：退到 **SSM/线性递推**（长序列训练 O(L)，梯度更良态）。

### 6.4 建议路线
1. **子集验证**（64–128 个代表 segment）：先证明分层 latent 可行；
2. 全细胞数据生成（一次 ~370 GB，分 trial 续跑）；
3. 分层模型 + TBPTT 训练；
4. 与“逐 segment 独立模型”基线对比，证明分层结构必要。
