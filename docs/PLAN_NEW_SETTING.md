# 换问题设定：三种路径的实施方案（2026-11-11）

> **定位**：本文件是 [`WM_PLAN.md`](WM_PLAN.md) 的**详细实施方案/附录**，不是独立于 WM_PLAN 的第二套计划。
> 总优先级、已关闭项、Stage 2/3 与时间表以 `WM_PLAN.md` 为准；本文件只展开 C2/B2/C1/A2 的具体做法。
>
> 背景：在“9 因子 + 全观测 + 冻结 T1 + 闭环 CL”框架下，确定性模型已到 **0.49–0.51 @200 ms**，
> 且接近非因果 jump 上界（0.48–0.58）。继续换模块收益接近零，故考虑换问题设定。

## 0. 一个关键判断：连续误差已贴近信息上界

- jump（非因果、输入摘要）200 ms：**0.48–0.58**；
- 我们因果模型：**0.49–0.51**；
- ⇒ 在“当前输入 + 9 因子状态”的信息量下，**连续误差的剩余部分基本不可约**。

因此：
- **提高连续精度** ⇒ 必须**增加信息**（新输入/新数据）；
- **提高事件保真（F1）** ⇒ 必须**改监督目标**（事件级），而不是连续 MSE。

## 1. 路径 A：更强输入（1–3 天，预期有限）

| 子项 | 做法 | 预期 | 成本 |
|---|---|---|---|
| A1 输入历史 | 预测器输入加 `u_{t-k..t}`（k=3）或 `Δu` | 小（u 已含 NMDA 去门控电导，历史部分被编码） | 1 天 |
| A2 输入预览 | 条件在 `u_{t..t+Δ}`（Δ=64/256）上（仿真里输入是给定的“计划”） | 中：接近 jump 上界（0.48–0.58），但不会低于它 | 1–2 天 |
| A3 突触级注意力 | 用现成的 `attn=True` 预测器（z 作 query，28 token 作 KV） | 中：可解释性 + 可能小幅提升 | 1 天 |
| A4 事件时间特征 | `time_since_last_ca_peak`、`time_since_bap` | 小–中（事件方向） | 0.5 天 |

**判断**：A2 是唯一可能明显改变连续误差的，但**受 jump 上界约束**；A1/A3/A4 是小幅。

## 2. 路径 B：事件级监督（2–5 天，针对 F1）

| 子项 | 做法 | 目标 |
|---|---|---|
| B1 事件标签 | 从真值提取：Ca 峰（时刻/幅度）、平台起止、V 峰 | 标签体系 |
| B2 点过程头 | 每帧 hazard λ(t)（log-normal 或 Weibull），损失 = 负对数似然 + 事件计数匹配 | F1 |
| B3 混合解码器 | 输出 = 平滑基底 + 在预测时刻叠加**参数化峰核**（非逐帧 spike） | F1 + 峰形 |
| B4 评测 | 峰 F1、时间误差分布、幅度误差、平台起止误差 | 事件指标 |

**注意**：B 不会改善连续 `model/L0`（事件是稀疏的），它改善的是**事件保真**。

## 3. 路径 C：新数据协议（1–2 周，真正的“换问题”）

| 子项 | 做法 | 目的 |
|---|---|---|
| C1 **STP + GABA_B + 随机释放** | 按 Blue Brain 配置改 `sim2`/`protocol2`，重生成数据（新目录） | 引入**隐藏状态**（u,x）与慢抑制，检验 latent 吸收隐藏动力学 |
| C2 **事件密集协议** | 提高 plateau/事件比例（如 plateau 从 44%→70%）、增加 trial 数（200→500） | 抬高信息上界，改善 F1 与 plateau 绝对误差 |
| C3 **更长仿真** | 5–10 s/trial | 慢门控（τ 450 ms）的长期行为 |
| C4 泛化集 | 不同 θ 范围/形态 | 检验泛化而非记忆 |

**成本**：C1 需可靠 mod 文件（用户可协助）+ 重生成（~数小时/组）；C2/C3 只需改协议参数 + 重生成。

**这是唯一能同时抬高连续与事件上界的路径**，但也是工作量最大的。

## 4. 建议的实施顺序（务实）

1. **C2（事件密集协议）**：最便宜、最直接抬高上界（改协议参数 + 重生成 1 组，~1 天）；
2. **B2（点过程头）**：在新数据上训练，直接冲 F1（2–3 天）；
3. **C1（STP/GABA_B）**：作为“隐藏状态”分支，检验 latent 的能力（需 mod 文件，1–2 周）；
4. A2（输入预览）作为对照/上界参考，不必作为主模型。

## 5. 判据

| 路径 | 成功判据 |
|---|---|
| C2 | 200 ms ≤0.45 或 plateau V MAE ≤8 mV；F1 ≥0.35 |
| B2 | F1 ≥0.5，且连续指标不退化 >10% |
| C1 | 在隐藏 STP 下，模型仍能保持 200 ms ≤0.6（证明 latent 吸收隐藏状态） |

## 6. 风险

- C2 可能改变 regime 分布，需重新校准 scaler；
- C1 需要可靠 mod 文件与重生成时间；
- B2 的 hazard 训练可能不稳（需 warmup/正负样本平衡）。
