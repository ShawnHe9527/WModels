# v5 世界模型改进方案（2026-11-09）

> 目标：在**保持“世界模型”形态**（latent 动力学 + 物理 decoder + 闭环 rollout）的前提下，
> 提升对 `apical_51` 的 9 因子状态、V 轨迹、Ca 峰的预测。
> 不改 9 因子定义、不改数据协议（除非开新分支）；所有改动默认关闭、可回退、单变量对照。

## 0. 为什么没有一开始就用 RSSM

| 原因 | 说明 |
|---|---|
| **全观测** | `s_t`（9 因子）是完整状态，`z_t=Enc(s_t)` 已是充分统计量；RSSM 的 posterior/prior/KL 主要为**部分可观测**设计 |
| **确定性动力学** | 给定 `(s_t,u_t)` 的下一步是确定的；RSSM 的随机 `z` 主要表达**随机性/多模态** |
| **可比性** | 9 因子协议、数据划分、评测口径是结论可比性的前提；先立住确定性基线，再谈随机 latent |
| **工程约束** | CPU、小数据、需要多 seed；KL 调参成本高，早期会拖慢主线 |

**但 RSSM 的两个部件正好对应我们现在的短板**：
- **随机 latent** → 事件“有/无”的多模态（F1 低）；
- **循环记忆 `h_t`** → 慢门控（τ 最长 450 ms）的长期保持（linear 档漂移）。

所以 v5 的计划是**选择性吸收**，而不是整体换成 RSSM。

## 1. v5 架构总览

```
s_t ──Encoder──► z_t (确定性)         ┌─► 随机头 (μ,σ) ─┐
u_t ──InputEnc──►                     │                  ▼
                                      │            z_t ~ N(μ,σ)
h_{t-1} ──GRU──► h_t ──Prior──────────┘
                                      │
z_t, u_t, θ ──Predictor──► z_{t+1}  (可加 h_t)
z_{t+1} ──Decoder──► ŝ_{t+1}  (残差)
                    ├─► 事件头 (峰时刻/幅度)
                    └─► 多视界头 (t+64/256/800)
```

- **保留**：latent 动力学、物理 decoder、闭环 rollout、9 因子输出；
- **新增**（全部默认关闭）：
  1. 输入历史/Δu/事件时间特征；
  2. 随机 latent（RSSM-lite）；
  3. 循环记忆 `h_t`（可选）；
  4. 事件头 + 多视界头；
  5. 快慢双 latent（后续）。

## 2. 分阶段实施

### Stage A：输入/输出（1–2 天，最便宜）

| 改动 | 设计 | 判据 |
|---|---|---|
| **A1 输入历史** | 给 predictor 喂 `u_{t-k..t}`（k=3）或 `Δu`、`Δs`；u 的慢尾（NMDA 70 ms）当前只给单帧 | 200/400 ms 改善 ≥5% |
| **A2 事件时间特征** | `time_since_last_ca_peak`（从真值 cai 峰算）作为额外输入 | F1 或 400 ms 改善 |
| **A3 逐因子输出缩放** | 输出 `Δs` 按因子/regime 归一化（目前统一 MSE） | linear 档改善 |
| **A4 事件 logits 输出** | decoder 额外输出“当前帧是否峰”的 logit | F1 ≥0.35 |

### Stage B：RSSM-lite（3–5 天，核心结构）

| 部件 | 设计 |
|---|---|
| 随机 `z` | `μ,σ = Enc(s_t,u_t,θ)`；`z = μ + σ⊙ε`（重参数化） |
| Prior | `p(z_t | h_t)`（`h_t` 来自 GRU）或 `p(z_t | z_{t-1},u_t)`（无 h 版） |
| Posterior | `q(z_t | h_t, s_t)`（训练时有 s_t） |
| KL | `KL(q‖p)`，**KL balancing**（Dreamer 式），权重逐步升 |
| 预测 | `z_{t+1} ~ p(·|h_t)`；decoder 用采样 `z` |
| 记忆 | `h_t = GRU(h_{t-1}, z_{t-1}, u_t)`（可选，先做无 h 版） |

- **先做“无 h 版”**（只是把确定性 `z` 换成随机 `z` + KL），验证是否改善事件；
- 若有效再加 `h_t`。
- 判据：F1 ≥0.4 或 200/400 ms 改善 ≥10%，且**不发散**；否则回退。

### Stage C：快慢双 latent（3–5 天，若 B 不够）

- 慢 latent：管门控/cai 趋势（低维，低通目标）；
- 快 latent：管峰/瞬变（高维，或事件头）；
- 两者拼接进 predictor；decoder 由慢 latent 为主、快 latent 做修正。
- 与之前的“双 decoder”不同：**分开的是 latent 的时间尺度**，不是 decoder。

### Stage D：长程（1–2 天）

| 改动 | 说明 |
|---|---|
| **D1 长滞后 OV** | 在 CL 512 轨迹上做 256/512 的 latent 一致性（当前只到 96） |
| **D2 多视界头** | 直接预测 `t+64/256/800` 的状态（jump 辅助），与 rollout 并联 |

### Stage E：基线（GPU 可用后）

- 膨胀 TCN（感受野 128+）、小 Transformer（PatchTST 式）；3 seed。

## 3. 评测口径（统一）

- 数据：`va_s2`（1 s）+ `te_s4_2s`（2 s 盲测）；
- 指标：`model/L0`（50/200/400/800 ms）、V MAE、cai 误差、Ca F1、发散率；
- 统计：**≥3 seed**，报告均值 + 范围；集成作为稳健性；
- 每个改动：**单变量、默认关闭、可回退**。

## 4. 风险与止损

| 风险 | 应对 |
|---|---|
| KL 塌缩/发散 | KL balancing、权重 warmup、监控 `σ` 与 `|z|` |
| 随机 latent 破坏确定性 | 推理时用 `μ`（确定性），训练时采样 |
| 训练变慢 | 先 1 seed 筛查，有效再扩 |
| 偏离“世界模型” | 保留 latent 动力学 + 物理 decoder + 闭环；不改成纯回归 |

## 5. 建议顺序

1. **Stage A**（便宜，1–2 天，1 seed 筛查）；
2. **Stage B（无 h 的 RSSM-lite）**（核心，3–5 天）；
3. **Stage D1 长滞后 OV**（便宜，可与 B 并行）；
4. **Stage C 快慢双 latent**（若 B 不够）；
5. **Stage E 强基线**（GPU 后）。
