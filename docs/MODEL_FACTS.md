### ⚠️ 测法陷阱

用「钳制 + 量松弛」测会得到一堆统一的 **22–28 ms** —— 那是**电紧张均衡时间**，
不是通道 τ。**必须从 `.mod` 解析式直接代入**。

### ⚠️ 协议时长 vs 慢态激发（重要）

| 量 | 值 |
|---|---|
| `Ca_HVA` 的 $\tau_h$ | **307–440 ms** |
| 常用协议窗（T0.3 的 `local`）| **150 ms**（40→190 ms）|
| ⇒ 150 ms 内最多能走的差距 | **29–39%** |

⇒ 🔴 **慢态比协议还慢 ⇒ 它在常用协议下根本没被激发**
⇒ 若要研究慢态，**必须用长窗协议**（≥ 800–1200 ms，即 2–3 $\tau_h$）。

**每室一个突触**：E 突触 **639** 个 · I 突触 **639** 个。

### ⭐ `g_NMDA` 的定义（含一个**瞬时**因子）

```text
A_NMDA' = -A_NMDA/tau_r ; B_NMDA' = -B_NMDA/tau_d      ← 状态（τr=2, τd=70 ms）
事件时 A += w*factor ; B += w*factor
g_NMDA = gmax * (B_NMDA - A_NMDA) * mggate(v)
mggate(v) = 1/(1 + exp(0.08*(-v))*(mg/3.57))          mg = 1 mM (Jahr & Stevens 1990)
```

| 因子 | 是状态？ | 动态范围（实测）|
|---|---|---|
| $g_{max}(B-A)$ | ✅ **状态**（突触史）| — |
| **`mggate(v)`** | ❌ **瞬时**（$v$ 的函数）| **116–171×**（当常数误差 90–104%）|

⇒ ⭐ **$g_{NMDA}$ 把「记忆」与「瞬时电压依赖」缠在一个标量里**。
⇒ 若把它当输入给一个无记忆模型，模型**无法拆开这两者**（尤其不知道**局部** $v$）。

### AMPA / GABA 无电压依赖

$$g_{AMPA}=g_{max}(B-A)\qquad g_{GABAA}=g_{max}(B-A)$$
⇒ 只要给事件序列，可**精确重建**（实测 rel RMS = **1.2e-16**，机器精度）。

## 7b. 🔴 **没法从外部「只关 NMDA」**（2026-10-14 实测，重要）

`ProbAMPANMDA2.mod` 里 `weight_NMDA` 被**局部参数遮蔽**：

```text
RANGE ... gmax, weight_NMDA
NET_RECEIVE (weight, weight_AMPA, weight_NMDA, ...) {   ← 同名参数【遮蔽】RANGE
     weight_AMPA = weight
     weight_NMDA = weight        ← 每次事件都被覆盖
     ...
}
```

**实测**（单个突触，1 个事件）：

| 操作 | `g_NMDA` 峰值 | `g_AMPA` 峰值 | 生效？ |
|---|---|---|---|
| 基线 | 7.289e-06 | 9.999e-04 | — |
| `syn.weight_NMDA = 0` | **7.289e-06**（不变）| 9.999e-04 | 🔴 **无效** |
| `syn.gmax = 0` | **0** | **0** | ✅ 但**同时关 AMPA** |

⇒ ⭐ **想干净地只关 NMDA，必须改 `.mod`**（加 `RANGE nmda_scale`，在事件里乘上）。
⇒ ⚠️ 这就是为什么原项目的 `off_NMDA` 用的是「**改 τ**」（`tau_d_NMDA` 是真 RANGE，
改它有效），而不是「关通道」。

⇒ 另有两个可选口径（⚠️ 见下，都需改 mod）：

| 口径 | 做法 | 消融什么 | 能从 Python 设？ |
|---|---|---|---|
| **(a) 改 τ** | `tau_d_NMDA: 70→3 ms` | 只消融**慢分量** | ✅（`tau_d_NMDA` 在 RANGE）|
| **(b) 完全关 NMDA** | `nmda_scale = 0` | 全部 NMDA 电流 | 🔴 ✗（需新增 RANGE）|
| **(c) 只关 `mggate`** | `mg → 0`（⇒ `mggate ≡ 1`）| 只消融**电压依赖** | 🔴 ✗（⚠️ **`mg` 不在 RANGE 里**，只在 PARAMETER 块 ⇒ 外部无法设）|

⚠️ 实测确认：`mg = 1 (mM)` 在 `PARAMETER` 块但**不在** NEURON 块的 `RANGE` 列表
⇒ **`syn.mg = 0` 会报错或无效**（未实测，仅从声明推断；建议实测确认）。
