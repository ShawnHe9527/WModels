# 2026-11-09 讨论纪要：Stage 1 改进路线与决策

> 目的：记录今日讨论的结论、优先级与判断依据，供后续执行与复盘。
> 总目标不变：**全神经元的分层联合世界模型**；`apical_51` 是 **Stage 1 方法验证**。

## 1. 决策

| # | 决策 | 依据 |
|---|---|---|
| 1 | **保留突触输入的强度信息**（AMPA/NMDA/GABA 电导、bAP） | 真实突触有强度差异；且这是后续“输入→输出影响”的研究对象 |
| 2 | **保留几何 `frac/side`** | 电缆方程/电紧张距离对位置敏感，去几何会丢物理 |
| 3 | **输入简化推迟到 Stage 2 前** | 全神经元每 synapse 输入会爆炸，届时必须汇总；Stage 1 先保证精度 |
| 4 | **分层 latent 留给 Stage 2** | Stage 1 只验证“简单输入能否学到动力学” |
| 5 | **物理残差（门控 ODE）只作消融/上界** | 否则会被质疑“抄答案”；需消融、探针、反事实、外推、真值 V 上界对照 |
| 6 | **当前优先解决“预测不准”** | 事件 F1、400/800 ms、linear 档漂移 |

## 2. 实验顺序（已确认）

1. **显式事件输出**（峰注入/点过程）—— 针对 F1；
2. **长滞后 OV**（CL 轨迹上 256/512 的 latent 一致性）—— 针对 400/800 ms；
3. **多视界直接头**（jump 辅助）—— 针对长程；
4. 之后（后备）：**RSSM-lite**（随机 latent）；
5. **快慢双 latent**：优先留给 **Stage 2**（不同 branch/segment 的时间尺度）。

## 3. 诚实判断（避免重复踩坑）

- `d_z=32` **无增益** ⇒ 表示容量不是瓶颈；
- 事件头作**辅助损失**只把 F1 从 0.248 提到 0.269 ⇒ 需要**显式输出**；
- 非 latent 基线（MLP 1.11 / GRU 299 / TDNN 2.65 @200 ms）**全部长程失败**，世界模型 0.45–0.67；
- 物理残差不是“主模型”，只用于解释“学到了什么”。

## 4. 未决问题

- 显式事件输出的实现方式（峰时刻回归 + 模板注入 vs 点过程强度）；
- 长滞后 OV 的 lags 选点（256/512）与权重；
- 多视界头与 rollout 的融合方式（门控/加权）；
- GPU 设备节点能否透传（影响 Stage E 强基线与大模型实验）。
