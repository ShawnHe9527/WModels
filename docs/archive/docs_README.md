## 写新文档的规范

| # | 规范 |
|---|---|
| 1 | 引用数字**必须标来源**（哪个脚本 / 哪次实测） |
| 2 | 区分「**实测**」与「**推理**」—— 推理要显式标注 |
| 3 | 🔴 **未做的事要显式写出**（避免后人误读为"已验证"）|
| 4 | 结论要标**强度**（⭐⭐⭐ 多重验证 / ⭐ 单一证据 / ⚠️ 有疑点） |
| 5 | 与 `MODEL_FACTS.md` 冲突时，以 `MODEL_FACTS.md` 为准并**更新它** |
| 6 | 设计变更**先改** `DESIGN_世界模型_定稿_v1.md`，再改代码 |
