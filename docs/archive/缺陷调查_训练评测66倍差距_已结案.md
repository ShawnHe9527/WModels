# 阶段 1 世界模型：训练/评测 66× 差距的根因与修复

**日期**：2026-10-15
**涉及文件**：`world/stage1_sec/wm_sec.py`
**结论**：此前的"世界模型学不会动力学"**不是**架构问题、**不是**过拟合，
而是**训练侧的时序索引错误** + **评测口径缺陷**。修复后模型首次在
80–800 ms 视界上**优于持久性基线**。

---

## 1. 症状

`logs/wm_v3.log`（修复前）：
```
ep 750/3000 | 编码=0.2156 观测=0.0099 roll=0.0016 obs(z)=0.0094
 → 最佳 epoch=250   闭环 V_rmse=2.339 mV   min-skill=-158.483
     h=   25 步 (  1.25 ms)  skill=-158.483
     h=12000 步 (600.00 ms)  skill=  +0.673
```
诊断脚本给出：
```
⇒ 归一化 MSE 0.003 (I0) → 原始 MSE = 5.434e-05 → RMS = 0.0074 nA
  但实测 eval 的 MSE_m(1.25ms) ≈ 0.024 → RMS = 0.1549 nA
  差距 = 21.0 倍  ⇒ 训练/评测仍不一致
```
换用逐通道归一化后差距达 **66×**。所有视界的 `rel_err ≈ 1.0`，
即"模型只会预测均值"。

---

## 2. 根因（两处，均在训练侧）

### 2.1 `gather_win` 时序颠倒（致命）

```python
# ❌ 修复前
s2 = s + n_warm                              # s2 = 预热段末尾
out = dict(
    X0 = AX[i, s2],                          # ← 取"预热末"的真状态
    U  = AU[i, s2 : s2+bt],
    Uw = AU[i, s  : s + n_warm],             # ← 却喂"预热开始"起的输入
)
```
即 **从未来的状态出发、喂过去的输入**。再叠加 `l_enc` 把该状态强行
监督到 `X[s2]`，预热段退化为纯无意义的恒等变换。

### 2.2 梯度只能回溯 `bt` 步

预热段全程 `no_grad` ⇒ 梯度最远只回溯 `bt=64` 步（**3.2 ms**），
而评测要跑 12000 步（**600 ms**）—— 相差 **190×**。

**因此此前声称的"① 统一训练/评测采样"实际从未生效。**

---

## 3. 修复

| # | 位置 | 修复 |
|---|------|------|
| 1 | `gather_win` | 返回 `Xw0 = X[s]`（窗口起点真状态）、`Xw1 = X[s2]`（预热末真状态） |
| 2 | `train` | `--bt 0`（**新默认**）= **全视界 BPTT**，梯度一直回溯到 `s` |
| 3 | `train` | 长 rollout 用 `torch.utils.checkpoint`（每步）省内存 |
| 4 | `train` | `--step-budget`（默认 48000）自适应减批：`batch = min(batch, budget/h)` |
| 5 | `train` | 截断模式（`--bt N>0`）保留，另加 `--warm-grad` / `--w-warm` |

## 4. 修复效果（同配置 `--h-max 1600`，最终评测）

| 视界 | 修复前 `rel_err` | 修复后 `rel_err` | 修复后 `skill` | 优于持久性 |
|---|---|---|---|---|
| 1.25 ms | 1.05 | **0.39** | −0.97 | ✗ |
| 5 ms | 1.43 | 1.06 | −155.4 † | ✗ |
| 20 ms | 1.15 | **0.57** | −4.10 | ✗ |
| 80 ms | 0.99 | **0.19** | **+0.50** | **✓** |
| 200 ms | 1.01 | **0.23** | **+0.27** | **✓** |

训练侧同步改善：`V_rmse` 从 2.57 mV 停滞 → **14.4 → 2.69 mV**；

† 5 ms 的 −155 是个**评测口径缺陷**（见下节），非模型缺陷。

## 5. 修复过程中暴露的 4 个"老二"缺陷（均已修）

### 5.1 `T_TEST` == 最长视界 ⇒ 最长视界只有 1 个起点

评测中视界 `h` 的合法起点是 `s ∈ [0, T-h]`。旧值 `T_TEST = 600 ms` 与
最长视界 600 ms 相等 ⇒ `smax = 0` ⇒ **只剩 s=0**，而 s=0 恰是
cond→test 边界的强瞬变（实测 s=0 归一化 MSE 1.260 vs s=5000 时 0.015，**差 82×**）。

证据：800 ms 视界的 skill 在 **所有 seed 下恒定 −12.02**，与模型无关。

**修复**：`T_TEST = 900 ms`（≥ 最长视界 × 1.5）；
视界改为 `(1.25, 12.5, 50, 200, 400, 800)` ms（相互间隔 ≥3×）。

### 5.2 指标被稀疏的 `i0` 完全主导

`Y[:,:,0]` = 突触电流 `i0`，只在 `syn`/`rebound` 协议里非零 ⇒ 重尾稀疏。

- 后果一：`RMSE_persist` 在**所有**视界上都 ≈0.030（基线几乎不衰减，
  因为大多是 0 对 0）⇒ skill 的分母趋于常数 ⇒ 失去判别力。
- 后果二：`signal_std` 随随机起点剧烈抖动（实测 4 起点 0.112 → 256 起点 0.166）。

**修复**：指标改为**逐通道 `MSE_c / var_c` 后取平均**
（每个观测通道等权、量纲统一为"相对各自方差"）。

### 5.3 `n_starts = 8` 采样不足

同一 ckpt、只改 `n_starts`（1.25 ms 视界 skill）：

| `n_starts` | 4 | 64 | 256 |
|---|---|---|---|
| skill | −14.8 | −63.2 | −57.7 |

⇒ `n_starts` 小时"哪个 epoch 最好"基本是随机数，早停与选优都跟着抖。

**修复**：默认 `--n-starts 64`；训练中周期评测用 16 省时间。

### 5.4 观测损失 `mean` 被稀疏零淹没 ⇒ 需补尾部惩罚

观测通道含大量 0，`mean` 被拉低 ⇒ 模型只需输出 0 就能拿到很小的均值
（`obs(z)` 停在 0.0085）。而评测用逐通道归一化后是 0.56。

**修复**：损失加 **top-10% 步均值**项（新增 `--w-top`，默认 0.5）。

### 5.5 训练间歇性爆炸（lr 调度不足）

| 版本 | 爆炸记录 |
|---|---|
| 固定 lr=1e-3 | ep2000 编码=0.0072 → ep2250 **647.35** → ep2750 0.0136 → ep3000 173.5 |
| warmup+cosine | ep100 编码=**4224** → ep250 743 → ep300 **15065** → ep400 7792 |

`clip_grad_norm(1.0)` **拦不住** —— 爆炸来自"优化器状态 + 持续偏离的梯度方向"。
代价极大：整个 run 的最佳点停在爆炸前的 ep250，剩余 150 epoch 全废。

**修复**（两道）：
1. **逐 epoch 余弦热重启**（周期 = `epochs/4`）：每周期末把 lr 降回 ~0；
   若真爆炸，下个周期会把状态拉回可行区。
2. **梯度硬上限** `--hard 10`：`‖g‖ > clip × hard` 就**丢弃该步**。

## 6. 顺带修复的工程缺陷

- **缓存键不含 `T_TEST`** ⇒ 改 `T_TEST` 后仍命中旧缓存。
  现键含 `_tset/_tcon/_ttest/_np`。
- **ckpt 不存架构标志**：`drop>0` 会在 MLP 里插入 `Dropout`，
  使 `Linear` 下标从 0/2/4/6 变成 0/3/6/9。加载时不传同样的 `drop`
  就报 `Missing E.2/E.4 + Unexpected E.3/E.9`。现已存 `drop/hid/nl`。

## 7. 教训（写给未来的自己）

1. **「训练损失 ≪ 评测误差」时，先怀疑训练侧的时序/索引错位**，
   不要急着归因过拟合或架构容量。
2. 任何 `X[t+k]` 与 `U[t]` 的窗口切片，**必须**用一行注释写清
   "起点是 `t` 还是 `t+k`"。
3. `no_grad` 预热 = 截断 BPTT，**必须**记录截断长度与评测视界之比。
4. 评测的**最长视界必须严格小于记录窗口**，否则起点退化为 1 个。
5. 指标的分母若来自"差分"或"稀疏信号"，短视界下必然病态；
   改**逐通道归一化**是通用解法。
6. 随机采样估计的指标，`n_starts` 必须大到让指标本身收敛
   （先做一次 `n_starts` 扫描，再固定）。
7. 训练损失里的 `mean` 若作用在稀疏量上，**必须**配一个尾部项。
8. `clip_grad_norm` 只按比例缩放，**不能**防爆炸；
   要加**硬阈值丢弃**或**周期性 lr 热重启**。
