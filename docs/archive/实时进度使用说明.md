**`内存PSI` / `磁盘PSI` 是最该盯的两个数**：它们是「被内存/磁盘阻塞的时间百分比」。
`磁盘PSI` 就是任务管理器里那个**磁盘 100%** 的精确度量（见
`docs/资源防护_WSL断连事故结案.md`）。

**「阶段日志 Ns 前更新」** 是判断死活的关键：
- < 90 s：正常（长视界的 batch 本来就慢）
- 90–180 s：黄色提示「可再等等」
- \> 180 s 且进程还在：**红色警告「疑似卡死」**

## 3. 训练脚本自身的前台进度条

直接前台跑时（`stdout` 是终端），训练脚本会**每 epoch 用 `\r` 原地重绘一行**：

```
  [████████░░░░░░░░░░░░░░░░]   400/1200  33.3%  ETA   25m18s  obs(z)=0.0063  RSS 2312MB  2875ms/ep  h=4173 bs=20
```

- **不污染日志**：只有在 `sys.stdout.isatty()` 为真时才启用。
  重定向到文件时 `\r` 会变成互相覆盖的残行（实测踩过）⇒ 已用
  `grep -c $'\r'` 验证日志中 `\r` 行数为 **0**。
- 控制开关：
  - `--progress -1`（默认）自动：是终端就开
  - `--progress 0` 强制关
  - `--progress 1` 强制开（调试用）
  - `--progress-every N` 每 N 个 epoch 刷新一次
- 任何**正式输出**（心跳、评测表、护栏告警）之前都会先 `_prog_clear()` 擦掉进度行，
  否则新行会从进度行中间接上去、输出变一锅粥。

## 4. 相关的日志

| 文件 | 内容 |
|---|---|
| `logs/train_MMDD_HHMM.log` | `world/train.sh` 的总日志（含各阶段头） |
| `logs/wm_stage<N>.log` | 第 N 阶段的完整输出（`run_safe.sh` 写的） |
| `logs/wm_curriculum_*.log` | 手动跑 `run_curriculum.sh` 时的总日志 |

⚠️⚠️ **阶段头（`################ 阶段 N：h-max=… ################`）只写在总日志里**，
不进 `wm_stage<N>.log`。所以 `watch.py` **必须同时读两个文件**，否则会显示
「未识别阶段」（实测踩过）。顺序很重要：**先总日志（拿阶段号），后阶段日志（拿进度）**。

## 5. 这一轮顺带修掉的 3 个真实缺陷

| # | 缺陷 | 症状 | 修法 |
|---|---|---|---|
| 1 | **冒烟跑覆盖正式结果** | 我跑了个 8 epoch 的小任务验证进度条，它把 `wm_sec_apical_51.json` 覆盖了；绘图脚本按 `mtime` 挑文件正好选中它 ⇒ 生成的 `结论.md` 写 `best_epoch=8`、`rel_err≈0.88`，**全错** | ① epochs<50 或 `--smoke` 时输出文件名自动加 `.probe<N>ep` 后缀，**绝不碰正式文件名**；② 绘图脚本改为**按 `score` 挑最好的**，不再按 mtime |
| 2 | **图/表错配** | `fig3` 用 `model_<sec>_dz<N>.pt`，而表和 JSON 可能来自 `stage2_dz16.pt` ⇒ 图是 A 模型、数是 B 模型 | `fig3` 从所读 JSON 的名字推出配套 ckpt（`wm_sec_stage2.json` → `stage2_dz16.pt`） |
| 3 | **`fig3` 转置写错** | `pV` 每项是 3 维 `(batch,P)`，`np.array(...).T` 会**反转所有轴** ⇒ `(P,batch,K)`，与 `VP[:,:K]` 的 `(batch,K,P)` 无法广播 ⇒ `ValueError: shapes (4,) (4,5)`，fig3 没生成 | 显式 `transpose(1, 0, 2)` |

另外 `fig4` 读 `js["loss_hist"]` 读错了位置（它在 `results[i]` 里），已修；
`fig5` 原来含中文而**本机一个 CJK 字体都没有**（`fc-list :lang=zh` 无输出）
⇒ 渲染成方框，已改为纯 ASCII 并加了字体自动探测（有 CJK 就用，没有就英文）。

## 6. 使用清单

**开跑前**

```bash
bash world/hygiene.sh              # 看磁盘/内存
bash world/train.sh                # 一键：体检 + 后台训练 + 实时面板
```

**训练中**

```bash
python world/watch.py              # 随时另开终端看进度
python world/watch.py --once       # 存一份快照
```

**训练后**

```bash
python world/analysis/plot_wm_sec.py           # 出 5 张图 + 结论.md
python world/analysis/plot_wm_sec.py --json results/stage1_wm_sec_v2/wm_sec_stage2.json
```

**停止训练**（结果不会丢，最优 checkpoint 实时落盘在 `live_*.pt`）

```bash
pkill -f 'world/stage1_sec/wm_sec.py'
# 续训：
bash world/stage1_sec/run_curriculum.sh 3      # 从 stage2 热启动跑阶段 3
```
