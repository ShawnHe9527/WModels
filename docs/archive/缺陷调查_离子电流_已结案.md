## 1. 曾经的错误结论与真正原因

### ① 假象：「去极化区误差 37%」

**原因：沉降时间不足。**
旧门禁把段钳到 V 后只跑 **400 ms** 就取稳态。而 `Ca_HVA.h` 的时间常数可达
**446 ms**（本克制表实测：163–446 ms）⇒ 400 ms 只有 ~0.9τ。

⇒ NEURON 与我们**处在瞬态的不同位置**，比的是两个不同的状态。

**修正**：改用**自适应收敛判据**（连续两个 100 ms 窗口的 V 剖面差 < 1e-3 mV），
至少跑 600 ms、上限 5000 ms。修正后去极化区误差立刻降到 **0.6–1.4%**。

| V | 400 ms（错） | 自适应（对） |
|---|---|---|
| −20 | 37.4% ❌ | **0.44%** ✅ |
| +20 | 10.1% ❌ | **0.28%** ✅ |
| +40 | 5.6% ❌ | **0.80%** ✅ |

### ② 假象：「超极化区电流偏小 30%」

**原因：`gIhbar` 不是段属性（关键坑）。**

```python
hasattr(seg, "gIhbar")     # → False ！
seg.gIhbar                 # → AttributeError: 'nrn.Segment' object has no attribute 'gIhbar'
dir(seg)                   # → 以 'g' 开头的属性：[]  （NEURON 段用 __getattr__ 动态解析）
```

我们模型的 gbar **只能**从
`sec.psection()['density_mechs'][mech][key]` 取（返回长度 = nseg 的 list）。

旧诊断脚本写成：
```python
if hasattr(s, "gIhbar") and hasattr(s, "m_Ih"):     # ← 永远 False
    tot += gIhbar * m_Ih * (v - ehcn)
```
⇒ **NEURON 侧的总电流从未包含 `Ih`**。
而 `Ih` 在 −65 mV 是**内向电流（负值）** ⇒ NEURON 的总和被**高估** ⇒ 比出 0.70。

**证据**（同一 compartment，x=0.5，V=−65）：

| 项 | 值 |
|---|---|
| NEURON `ina+ik+ica+i_pas` | +0.001345 |
| ours（去掉 Ih） | +0.001339 ⇒ **比 0.9955** ✅ |
| ours 的 Ih | −0.000415 |
| NEURON 应有的 Ih（用 `psection` 的 gIhbar 算）| −0.000413 |

⇒ 两边**逐项吻合**。补上 Ih 后该用例比值变为 **0.9917** ✅

### ③ 假象：「`i_membrane` 读不到」

`getattr(seg, "i_membrane")` 报 *"the mechanism does not exist"*。
NEURON 里该机制默认不插入 ⇒ 总膜电流必须**自己拼**：
`ina + ik + ica + i_pas + Ih`。

### ④ 假象：「`ik` 与单机制不符」

`ik` / `ica` 是**多个机制的和**（`Im`+`SKv3_1`+`SK_E2` 都写 `ik`）。
拿它当"某单个机制的电流"是错的 —— 早期脚本的"比值 0.02"之类全是这个伪影。

正确做法是**机制消融**（把 `g<Mech>bar` 置零测差），但消融同样要小心：
SEClamp 只钳在两端，**中间 compartment 的 V 会因消融而漂移** ⇒ 消融值被污染。
只有在 V 几乎均匀时消融才干净。

## 4. 方法论教训（写给以后）

1. **⚠️ 任何"稳态"对照都必须用自适应收敛判据，绝不用固定时长。**
   本模型的慢门控 τ 达 446 ms ⇒ 固定 400 ms 必然得出错误结论。
   判据建议：连续两窗口的**状态变量**（不只 V）变化 < 阈值。

2. **⚠️ NEURON 段属性 ≠ `psection()` 字典。**
   NEURON 只把 `STATE`/`RANGE` 中的一部分暴露为段属性；
   `gIhbar`、`ik`、`ica` 这类要走 `psection()`。
   **凡是"取不到就当没有"的写法，都会静默漏项。**
   ⇒ 取参数时应当**报错**而不是跳过。

3. **⚠️ 共享名电流（`ik`/`ica`）不能当单机制电流用。**
   多机制写同一 ion ⇒ 读到的和。拆分只能靠消融（且消融要求 V 均匀）。

4. **⚠️ 对照两个实现时，必须先确认它们处于同一状态。**
   本次三次"发现缺陷"全部源于**比较条件不一致**（不同时刻 / 不同组成 / 不同机制集合）。

5. **⚠️ 诊断脚本本身要有自查。**
   例如：消融之和应等于总电流；若不等，说明消融不完整（本次 `pas` 被跳过、
   `Ih` 取不到属性，两点都暴露了）。
