## 0. 构想原文（用户 2026-10-18 重申，逐字保留）

> 我了解到目前深度学习网络中有世界模型这一概念。世界模型可以预测下一次的输出。
> 我的构想是，**以一段神经元 section 举例**，将该 section 的**所有有可能影响输出的因素**
> 作为输入，包括：
> - section 几何状态（长短、粗细、形状）
> - 膜状态
> - 各离子通道
> - 突触状态
> - 胞体是否放电
> - Ca 平台
> - 突触激活
> - **等一切有可能影响输出的因素**
>
> 然后**将这段 section 为模板**，将这些输入经过世界模型**编码器并不断降维简化**，
> 最终形成一个 **embedding 网络**；该 embedding 网络可以给出**降维简化后输出**；
> 世界模型**预测器预测出下一阶段 embedding 网络的状态**；
> 然后可以通过预测出的状态**经解码后得出下一时刻神经元的各因素状态**，
> 即预测出下一阶段神经元的状态。

## 1. 构想的形式化

### 1.1 三个要素（对一段 section）

| 符号 | 名称 | 是否随时间变 | 内容 |
|---|---|---|---|
| $\theta_s$ | **段模板**（静态条件） | ❌ 整条轨迹不变 | 几何 + 通道密度 + 被动参数 + 机制存在性 |
| $s_t$ | **神经元状态**（动态因素） | ✅ | 膜电位 + 门控 + 钙 + 突触电导 + 放电/Ca 平台标志 |
| $u_t$ | **外部驱动** | ✅ | 来自上游/下游的端口电位（或注入电流）|

> **三者合起来 = 用户说的"所有可能影响输出的因素"**。
> $\theta_s$ 是"这段是什么样的"，$s_t$ 是"它现在在什么状态"，$u_t$ 是"外面正在推它多少"。

### 1.2 计算流程

```
                    ┌──────────────────────────────────────────┐
   θ_s (段模板) ────┤                                          │
   s_t (当前状态) ──┤→  Enc(编码器, 逐层降维)  →  e_t ∈ R^dz   │  ← "embedding 网络"
   u_t (外部驱动) ──┤                                          │
                    └──────────────────────────────────────────┘
                                    │
                                    ▼
                    e_{t+1} = Pred(e_t, θ_s, u_t)     ← "世界模型预测器"
                                    │
                                    ▼
                    ŝ_{t+1} = Dec(e_{t+1})            ← "解码器"
                                    │
                                    ▼
                        下一时刻的**各因素状态**
                        （V、门控、钙、突触电导、放电标志…）
```

### 1.3 关键设计原则（由构想直接推出）

| # | 原则 | 理由 |
|---|---|---|
| **P1** | **$\theta_s$ 必须进输入** | 用户明确列出"几何、各离子通道"。缺了它，模型不知道自己在处理哪一段，只能靠记忆硬背 |
| **P2** | **$s_t$ 必须进输入** | 用户明确列出"膜状态、突触状态、Ca 平台"。这是记忆的唯一来源（静态网络无内部状态）|
| **P3** | **编码是"降维"，但要可解码** | "降维简化"+"解码后得出各因素状态" ⇒ embedding 必须**保留足够信息** |
| **P4** | **$\theta_s$ 也进 Predictor** | 预测器要知道物理参数才能推演化（不同段的 τ、电导完全不同）|
| **P5** | **预测目标是"状态"本身** | 用户说"预测出下一阶段神经元的状态" —— 不是只预测某个电流 |

### 1.4 与旧文档的差异（必须改的三处）

| 项 | 旧（STAGE1/DESIGN） | **新（本定稿）** |
|---|---|---|
| 输入 | 24 维，**只有边界条件** | 含 $\theta_s$ + $s_t$ + $u_t$，**完整** |
| 输出 | `[I0, I1, Vm, ΔV×5]` | **各因素的下一时刻状态** |
| V 的地位 | "V 不算状态" | **膜状态**（含 V）属于 $s_t$ |

## 2. 输入 / 状态 / 输出 的完整字段表

> ⚠️ 下表的**字段选择**依据：① 用户列出的因素 ② 实测的模型事实（`MODEL_FACTS.md`）
> ③ 实测"跨段差异巨大"的证据（见 §2.4）。
> ⚠️ **具体维度待 §6 的开放问题确认后锁定。**

### 2.1 $\theta_s$ —— 静态条件（段模板，一次算好、整条轨迹复用）

| 分组 | 字段 | 依据 |
|---|---|---|
| **几何** | $\log_{10}L$、$\log_{10}\bar d$、**锥度** $d(1)/d(0)$、$\log_{10}\text{nseg}$ | 实测跨段：$L$ 差 **158×**、$\bar d$ 差 **52×**（`apical_51` 沿段自身 taper 1.54→1.29 µm）|
| **通道密度** | $\log_{10}\bar g$：`Ca_HVA`, `Ca_LVAst`, `Ih`, `Im`, `NaTs2_t`, `SK_E2`, `SKv3_1`, `pas` | 8 种，apical 全套 |
| **axon 通道** | $\log_{10}\bar g$：`NaTa_t`, `Nap_Et2`, `K_Pst`, `K_Tst` | 快 Na/K **只在 axon**（实测），是放电机器 |
| **钙动力学** | $\log_{10}\gamma$、$\log_{10}\tau_{decay}$、$\log_{10}cai_{min}$ | `CaDynamics_E2` 的 `decay = 35.7 ms`，是**记忆载体** |
| **被动** | $\log_{10}g_{leak}$、$e_{leak}$、$c_m$、$\log_{10}R_a$ | 决定静息与时间常数 |
| **区域** | one-hot（basal / apical / axon / soma）| 结构先验 |

### 2.2 $s_t$ —— 神经元状态（动态因素，要预测）

| 分组 | 字段 | 说明 |
|---|---|---|
| **膜电位** | $V$（逐 compartment 或导频点）| 用户说的"膜状态"核心 |
| **门控变量** | 每种机制的每个 gate，逐 compartment | 用户说的"各离子通道"的**状态**部分 |
| **钙浓度** | $cai$（逐 compartment 或导频点）| 用户说的"Ca 平台"的物理载体 |
| **突触状态** | $g_{ex}$、$g_{inh}$（逐 compartment）、$E_{ex}$、$E_{inh}$ | 用户说的"突触状态 / 突触激活" |
| **放电标志** | `spike`（0/1 或 logit）| 用户说的"胞体是否放电" |
| **Ca 平台标志** | `plateau`（0/1 或 logit）| 用户说的"Ca 平台" |

### 2.3 $u_t$ —— 外部驱动

| 字段 | 说明 |
|---|---|
| $V_{J0}, V_{J1}$ | 两端来自邻居的电位（**端口边界条件**）|
| （可选）$I_{inj}$ | 直接注入电流 |

> ⚠️ **$V_J$ 的地位**：它是"本段之外"对"本段"的影响，属于**外部驱动**，不是"段内状态"。
> 物理上两端的 $V_J$ 一般**不相等**（中间隔着本段的轴向电阻）。
> 阶段 2/3 拼接时 $V_J$ 由邻居共同决定 ⇒ 不能前馈顺序传播，需全局求解。
> （这一点不影响阶段 1：阶段 1 中 $V_J$ 由我们给定的协议驱动。）

### 2.4 为什么这些项不能省（实测证据）

| 证据 | 数字 | 出处 |
|---|---|---|
| 空间分布不能被池化 | 同一总电导铺在"一端"vs"均匀"，端口电流差 **94.4%** | `world/probes/probe_input_spatial.py` |
| 通道密度跨段差异巨大 | $g_{SK\_E2}$ 差 **49825×** | `MODEL_FACTS.md` |
| 几何跨段差异巨大 | $L$ 158×、$\bar d$ 52× | 本目录实测 `catalog` |
| 电压**不是**状态时，观测冗余 | $I_0 = g_{b0}(V_0-V[0])$ 可解析重建，残差 **1.5e-06 nA** | 2026-10-18 诊断 |

## 4. 阶段 1 的实验目标与验收标准

### 4.1 研究对象：`apical_51`（推荐，备选 `apical_37`）

| 实测项 | `apical_51` | 为什么选它 |
|---|---|---|
| 区域 | apical，**9 种机制全套** | basal 只有 `pas`+`Ih` ⇒ 测不了 Ca/Na/SK |
| nseg | **11** | 适中；$u_t$ 维数可控 |
| $L$ / $\bar d$ | 215.5 µm / 1.34 µm | 非极端 |
| 位置 | 796 µm（688→904）| **Ca 热点带 685–885 µm 中心** |
| $g_{Ca\_LVAst}$ | **0.2067** | 比远端高 **91×**（`apical_38` 仅 0.0023）⇒ Ca 效应可测 |
| 父 / 子 | `apical_50` / `apical_53`, `apical_52` | **有子段**，为阶段 2 铺路 |
| 记忆时标 | CaDynamics 35.7 ms + Ca_HVA.h 163–446 ms | 长记忆可测 |

**备选 `apical_37`**：nseg=13、$g_{Ca\_LVAst}$=0.1579（分布更均匀）、父 `apical_36` / 子 `apical_45`,`apical_38`。

### 4.2 必须同时通过的四层基线对比

> ⚠️ **这是从上一轮失败中得到的硬教训**：只看"模型 vs 持久性"会失去判别力。
> 必须四层并列，缺一不可。

| 层 | 基线 | 作用 |
|---|---|---|
| **L0** | 复制上一步 $s_{t+1} := s_t$ | 最低门槛（dt 小 ⇒ 近乎完美，不能单独用）|
| **L1** | **静态映射** $s_{t+1} = f(\theta_s, s_t, u_t)$ **无记忆**（MLP 或岭回归）| ⚠️ **最关键**：若世界模型赢不过它，说明"记忆/递推"毫无价值 |
| **L2** | 该协议自身的时间均值（**作弊上界**）| 若世界模型输给它，说明连"典型水平"都没学到 |
| **L3** | 完整 NEURON 仿真 | 真值 |

**判定：世界模型必须同时优于 L0、L1、L2。**

### 4.3 指标规范

| 指标 | 定义 | 为什么 |
|---|---|---|
| **逐协议归一化 rel_err** | 每个协议**用自身的 std** 归一化，再聚合 | ⚠️ 实测：观测方差 **94.3% 来自协议之间**；用池化 std 会把误差压小几十倍 ⇒ 假象 |
| **多视界** | $h \in \{1, 5, 25, 100, 400, 1600\}$ 步（dt=0.05 ⇒ 0.05/0.25/1.25/5/20/80 ms）| 单步指标会被"平滑信号"骗过（实测每步只变 0.25%）|
| **逐因素报告** | 每个状态因素单独报 | 避免某个易预测因素把平均拉好看 |
| **物理自洽性** | 从 $\hat s_{t+1}$ 反算 $C\,dV/dt$ 与 $\hat I_{ion}$，检查残差 | 防止"数值对但物理错" |

### 4.4 阶段 1 验收标准（分三档）

| 档位 | 标准 |
|---|---|
| **最低（必须）** | 所有因素在**所有视界**上 `rel_err` 同时优于 L0、L1、L2 |
| **达标** | 1.25 ms 视界 `rel_err < 0.1`；80 ms 视界 `rel_err < 0.3`；embedding 维度 $d_z < d_s / 2$ |
| **优秀** | 80 ms 闭环 `rel_err < 0.1`；物理自洽性残差 < 5%；embedding 可解释（有物理含义的降维）|

## 5. 数据协议要求（由上一轮失败直接推出）

| # | 要求 | 上一轮的失败证据 |
|---|---|---|
| **D1** | 窗口 **≥ 1000 ms**，相位化（settle → conditioning → test）| 实测 7.5 ms 窗口时"复制上一步" R² 已达 0.9984 ⇒ 任务平凡 |
| **D2** | **两个端口都要动**，且是**平滑带限**驱动（周期 20–500 ms 正弦叠加）| 实测：协议内 $V_0$ 的慢变化只有 **0.02 mV**，93% 是白噪声 |
| **D3** | **删掉 ±0.5 mV/步 白噪声**（不物理：真实邻居电位被膜电容平滑，$\tau_m$ ≈ 10–30 ms）| 同上 |
| **D4** | 必须**激励慢态**：让 `Ca_HVA.h`（τ 163–446 ms）、`Ih.m`（10–79 ms）、`cai`（35.7 ms）都被推离稳态 | 实测 `cai` 动态范围 440×、`Ih.m` 83× 才够 |
| **D5** | 协议必须**覆盖强非线性区**（Ca 再生 ≥ −53 mV）| `apical_51` 已知双稳 |
| **D6** | 训练/验证**按协议划分**（不是按时间段）| 防止信息泄漏 |
| **D7** | 数据格式：逐 key 独立 `.npy` + 真 mmap | `.npz` 不能 mmap ⇒ 760 MB 常驻内存 ⇒ 曾致 WSL 断连 |

## 9. 继承的硬教训（来自失败，必须遵守）

| # | 教训 | 来源 |
|---|---|---|
| 1 | **训练损失 ≪ 评测误差时，先怀疑训练侧时序/索引错位**，不要急着归因过拟合 | 实测：`gather_win` 时序颠倒导致 66× 差距 |
| 2 | **指标分母若来自"差分"或"稀疏信号"，短视界必然病态**；必须逐协议归一化 | 实测：池化口径 0.048 vs 诚实口径 1.03 |
| 3 | **目标里若含"可由输入代数导出"的量，模型会抄捷径** | 实测：$I_0$ 由 $V_0,V_{end}$ 解析重建，残差 1.5e-06 nA |
| 4 | **感知器无记忆 ⇒ 必须显式给状态** | 用户构想与实测一致 |
| 5 | **进程静默 = 无法判断死活** ⇒ 必须有心跳日志 + 实时落盘 | 两次事故 |
| 6 | **`torch.utils.checkpoint` 必须显式导入**（`import torch` 不暴露子模块）| 实测 |
| 7 | **只调 `torch.set_num_threads` 不管用**，OMP/MKL 要在库加载前用环境变量钉死 | 实测：47 线程 → glibc arena 碎片化 |
| 8 | **`.npz` 不能 mmap，单个 `.npy` 可以** | 实测：760 MB 常驻 ⇒ WSL 断连 |
| 9 | **冒烟/探针跑必须用不同输出文件名**，否则覆盖正式结果 | 实测：8 epoch 探针覆盖了 1200 epoch 的 JSON |
| 10 | **阈值判据必须"相对基线"**（本机静态已有 1000+ MB swap）| 实测：看门狗第 0 秒误杀 |
