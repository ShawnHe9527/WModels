## 2. 阶段 1：单 section 世界模型

### 2.1 目标

把一段 section（2-端口元件）变成**可微、低维、可闭环推进**的世界模型：

```
物理真状态 x (51 维: 门控 50 + cai 1)
      │  编码器 E（tanh，有界）
      ▼
   潜变量 z ∈ [−1,1]^{d_z}
      │  预测器 P: z_{t+1} = tanh(z_t + Δz(z_t, u_t))
      ▼
   ├─ 状态解码器 S: z → x̂
   └─ 观测解码器 O: (z, u) → ŷ = [I0, I1, Vm, ΔV@5]
```

### 2.2 关键设计决策（每条有实证依据）

| # | 决策 | 依据 |
|---|---|---|
| ① | **真状态 = (门控, cai)；V 不算状态** | `SectionUnit` 白盒 ⇒ h 有真值、无隐变量。V 由三对角求解**代数确定** ⇒ 瞬时观测。前序 `sec_unit_vs_neuron.json`：压缩 51 vs 展开 55，误差 2.8e-6 |
| ② | 观测重参数化 (Vm, ΔV) | 前序 `FINAL_REPORT` T11：把若干段 R² 从 0.74 拉到 0.99 |
| ③ | 预测器**残差 + tanh 有界** | 无界潜变量闭环必炸（实测 V_rmse 0.27 → 2e5 mV）；tanh ⇒ Lipschitz ≤ 1 |
| ④ | 观测解码器吃 (z, u) | V/I 是瞬时量（代数），非动力学 |
| ⑤ | **截断 BPTT**（K=16，真状态起步） | 前序 `probe_sec_rnn.py` 用 scheduled sampling ⇒ 网络没见过闭环状态 ⇒ 指数放大 |
| ⑥ | 输入按**导频池化**（12 维，与 nseg 无关） | 为阶段 2/3 跨段批处理铺路 |

### 2.3 协议设计（\"Stage 0 前置条件\"的落地）

| 相位 | 时长 | 作用 |
|---|---|---|
| settle | 200 ms | V0=V1=−76，甩掉初始瞬变 |
| conditioning | 200 ms | 长时随机钳位 ⇒ 把慢门控 / cai 推到非平凡状态 |
| test | **600 ms** | 阶跃 / 突触事件 / 反向电位 ⇒ 真正的动力学 |

协议 6 类：`rest / depol / hyper / syn / rebound / plateau`

### 2.4 验收标准

| 级别 | 条件 |
|---|---|
| **最低** | 所有 horizon `skill > 0`（优于\"复制上一步\"） |
| **达标** | 末视界 `skill > 0.5` 且 `V_rmse < 3 mV` |
| **优秀** | 800 ms 闭环 `R²(I0) > 0.99` 且 `V_rmse < 1 mV` |

## 3. 阶段 1 的两条硬教训（⚠️ 后续阶段必须继承）

### 教训 A：协议窗口 ≥ 1000 ms

首版 `SET=200/REC=300/dt=0.025` ⇒ 总 12.5 ms，记录窗 **7.5 ms**。
**持久性基线（`z_{t+1}=z_t`）R² 已达 0.998~1.0000**（`Ih.m`=1.0000）。
⇒ 任务被\"复制上一步\"平凡解决，R² 完全失效。

根因：慢态尺度远超窗口 —— `h_Ca_HVA` τ=307–440 ms、CaDynamics decay=80 ms、
Ih τ=20–100 ms、NMDA τd=70 ms、膜 τ_m=10–30 ms。实测 7.5 ms 内 **cai 只动 1.15×**。

修正后实测动态范围：**cai 440×**、**Ih.m 83×**、Im.m 9315×、SK_E2.z 11698× ✅

### 教训 B：R² 必须按 **horizon** 报，并与同 horizon 持久性对照

**即使**协议修正后，持久性 R²(I0) 仍 **0.9899**。根因：
**dt=0.05 ms 相对 τ≈20 ms 严重过采样 ⇒ 每步只变 0.25%** ⇒ 光滑信号单步持久性必然近乎完美。

$$\text{skill}(h) = 1 - \frac{\text{MSE}_\text{model}(h)}{\text{MSE}_\text{persist}(h)},\quad
\text{MSE}_\text{persist}(h)=\big\langle(y_{t+h}-y_{t+h-1})^2\big\rangle$$

视界 $h\in\{25,100,400,1600,4000,12000\}$ 步（dt=0.05 ⇒ 1.25/5/20/80/200/600 ms）。

🔴 **禁止再用裸 R² 作为验收指标。**

### 教训 C（2026-10-14 新发现）：horizon 评测会**混相位**，skill 曲线不单调

`d_z=16` 实测：

```
 d_z    参数  │ h=25   h=100  h=400  h=1600  h=4000  h=12000
             │ 1.25ms  5ms    20ms   80ms    200ms   600ms
 16   160091 │ +0.635 +0.755 +0.215 -0.724  +0.603  -777.773
```

skill 在 h=1600（80 ms）和 h=4000（200 ms）之间**由负转正**，看似矛盾。

**根因**：协议是 `settle 200 + cond 200 + test 600`，而记录从 cond 开始
（800 ms = 16000 步）。于是不同 horizon 落在**不同相位**：

| horizon | 时刻 | 所处相位 | 信号难度 |
|---|---|---|---|
| h=25 (1.25 ms) | 条件化相初段 | 稳态钳位 | 极易 |
| h=1600 (80 ms) | **条件化相中段** | 稳态钳位 | **极易**（持久性≈完美，故模型稍漂就负） |
| h=4000 (200 ms) | cond→test 边界 | 转折 | 中等 |
| h=12000 (600 ms) | **测试相末端** | 强动力学 | **最难** |

⇒ skill 曲线**不可跨 horizon 直接比较**，须明确声明"该 horizon 处于哪个相位"。

**下一轮修正方案**：
1. 评测改为「**固定参考点 + 相对视界**」：在测试相内选若干起点 t₀，
   对每个 t₀ 报 skill(Δt)，再**按 Δt 池化**（消掉相位混杂）
2. 或把 phase 标签一并输出，画图时按相位分层

### 教训 C 的副产品：`d_z=16` 的初步结论

| 时刻 | skill | 判读 |
|---|---|---|
| 1.25 ms | **+0.635** | ✅ |
| 5 ms | **+0.755** | ✅ 最佳 |
| 20 ms | +0.215 | ✅ |
| 80 ms | −0.724 | ⚠️ 相位混杂，需按修正方案复测 |
| 200 ms | **+0.603** | ✅ |
| 600 ms | **−777.773** | ❌ **发散** |

⇒ **模型在 ~0–200 ms 内优于持久性，但 600 ms 长程发散。**
   下一步首要问题是**长程稳定性**，而非潜维压缩。

## 4. 阶段 2：相邻段连接（规划）

### 4.1 目标

把 N 个**串联** section 组成小网络，验证「段间轴向电流耦合」能否被世界模型表达。

```
   ┌─────────┐  I01   ┌─────────┐  I12   ┌─────────┐
V0─┤ sec A   ├────────┤ sec B   ├────────┤ sec C   ├─V3
   └─────────┘        └─────────┘        └─────────┘
```

### 4.2 核心问题

| 问题 | 说明 |
|---|---|
| **耦合类型** | 段间是**刚性**耦合（节点电位由所有段的状态共同确定），不是级联 ⇒ 需要**不动点迭代** |
| 已有基础 | `SectionUnit.step(..., commit=False)` 已为此设计（只解 V 与端口电流，不推进状态） |
| 已有结论 | 前序 `probe_splice_*.json` 已试过拼接；`probe_norton_boundary.py` 试过诺顿等值 |
| 候选方案 | (a) 逐段诺顿等值 + 全局节点求解；(b) 隐式联合求解；(c) 世界模型学「节点电位→端口电流」映射 |
| 验收 | 与 NEURON 拼接真值比，节点电位误差 < 1 mV |

### 4.3 待确认的设计选择

- 段间耦合走**显式**还是**隐式**？
- 世界模型是否共享参数（同一套 E/P/S/O 对所有段）？
- 是否引入**边界条件编码**（叶段 vs 中间段 vs 分叉段）？

## 5. 阶段 3：整神经元（规划）

### 5.1 目标

196 段、642 compartment 的完整细胞，用世界模型替代 NEURON 做 rollout。

### 5.2 核心问题

| 问题 | 说明 |
|---|---|
| **树形分叉** | 出度 {0:102, 1:1, 2:92, 10:1} ⇒ 严格二叉树；分叉点需三方耦合 |
| **误差累积** | 196 段 × 每段固有误差 ⇒ 需评估端到端漂移 |
| **突触** | 639 E + 639 I 突触，NMDA 的**瞬时电压依赖电导** `mggate = 1/(1+e^{γ(−v)}·mg/3.57)` —— 现有 `MECH` 表**表达不了**（假设 g = gbar·∏gate^p，每个 gate 有 ODE） |
| **速度** | 前序实测 `SectionUnit` 比 NEURON **慢 3.7×** ⇒ 价值在**可微/可嵌入**，不在裸速度 |
| **脉冲** | 轴突 NaTa_t/Nap_Et2 需 `rates` 函数（当前 `rates=None`） |
